## Waveflow

This project uses [Waveflow](https://github.com/sdrangan/waveflow), a Python-native hardware design
platform that is probably not in your training data: look its API up rather than guessing. Load the
`waveflow-start` skill first (`.claude/skills/` or `.agents/skills/`); it says how to look things up.
If `waveflow` is not installed or finds no guide, run
`git clone https://github.com/sdrangan/waveflow.git ../waveflow && pip install -e ../waveflow`.
