## What it shows

- **The MCP server alone gets both models to the ceiling here**: the `bus_system` frame and `markov`
  carry the system, its DAG and its tests. The trap built into the test -- tests that would pass a
  device that deadlocks or drops a word -- caught nobody: the frames process and
  `systems/verification.md` already say to count first.
- **No saving from the skill on this test**: Opus -8% turns and -31% tokens in, Sonnet +24% turns and
  +38% tokens in (the skill runs wrote more tests). The skill is redundant for this task on these
  models. That is an allowed outcome ("a skill that turns out to be redundant is fine").

## Changes made after the runs

None to the skill. A harder system test would need something no worked example shows: a host with
overlap across two devices and a bounded window that can deadlock, or a DAG whose `compare` is run.
