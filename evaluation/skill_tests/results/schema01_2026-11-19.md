## What decided the differences

- **C7, both MCP-only runs on Opus and Sonnet:** field reads wrapped in `int()` / `np.asarray()`
  with no reason given (`Op(int(cmd.op)) == Op.END`, `n = int(cmd.nsamp)`): 10 and 13 lint hits.
  Both skill runs keep the values as they come; their few `int()` calls are at the plain-Python
  boundary, commented, as the skill says.
- **D6, Opus MCP:** one command per firing with a `static bool halted` kept across firings. The spec
  says nothing is kept between commands, and state carried across firings is the `hls::task` reset trap.
- **E2, Opus skill:** imported `FixedField` from `waveflow.hw.dataschema` once, then fixed it.
- **Haiku, MCP:** the opcode and the tag are 8-bit `IntField`s, not `EnumField`s; no `ArrayUtilsStep`;
  the C++ calls methods that do not exist (`DetectCommand::read_stream(s_in, W)`,
  `write_stream(m_out, W)`) and extracts samples by bit offset (`get_field(..., j * 12, 12)`) at one
  sample per 32 bits; the Python sizes the sample burst at one sample per 32-bit word (3 words are 5
  there; the worked example passes only because the overrun runs off the end of the input) and its
  64-bit check packs the samples by hand (`(s & 0xFFF) << (j * 12)`) and asserts nothing.
- **Haiku, skill installed:** the skill was offered and never loaded.  The header script imports
  modules that do not exist (`waveflow.codegen`) and was never run; the model has no
  `pulse_det_model(words_in, word_bw)` and its only check is `len(output) >= 3`; the C++ is a sketch
  whose reads and writes are comments, with a line of Python (`yield self.event()`) in it.

## Waveflow defects the runs found

- The generated C++ `<elem>_array_utils::get_nwords<W>(n)` counted densely packed elements (Opus,
  MCP).  Fixed on `fix/arrayutils-get-nwords`.
- `from_real(v, T)` returns an array of the cached format class, not `T`, when `T` was specialized
  with `include_dir`, so `write_uint32_file(..., elem_type=T)` refuses it (Opus MCP, Sonnet skill).  Open.
- No Python comparison of a signed `FixedField` with an unsigned one (Opus, both arms).  Open.
