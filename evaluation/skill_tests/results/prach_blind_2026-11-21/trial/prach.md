# Task

Build a 5G NR PRACH searcher for a reasonable config in a 20 MHz channel.

## How to work with me

I will not be available to answer questions while you work. Wherever you would stop and wait for
my decision, instead write an entry in `decisions.md` in this folder (numbered, one per pause):
the question, the options you weighed, the one you recommend and why. Then carry on with your
recommendation as if I had approved it.

Vitis HLS and Vivado are not installed on this machine, so nothing can be synthesized or
co-simulated here. Where a number would need a synthesis run, say so.
