## Findings and what was done

| | finding | done |
|---|---|---|
| A | `harness()` and `StreamSink` wrote >64-bit words flat (no `word_chunks`): pysim `ValueError: For word_bw > 64, packed must be a 2D array-like`; RTL `FATAL: bundle vectors/s_in holds 1-chunk words; this AxisMaster's port takes 2` | **fixed**: both pass `ceil(W/64)`; `tests/hw/test_harness_wide.py` |
| B | After a fatal error the top's AXI-Stream register slice completes 2 more `s_in` handshakes (the body reads none) | **documented**: `patterns/command_response.md`, *Errors are fatal* |
| C | csynth freshness ignored `gen/<top>.tcl` (a part change stayed UP-TO-DATE); `--force-step csynth` "PASSED (0.3 s)" without running Vitis | **fixed**: the RTL stamp hashes the `.tcl`; a forced step forces its inner DAG (`BuildStep.forced`); `tests/build/test_forced_inner.py` |
| D | A failed step left `run_dag_cli` exiting 0 | **fixed**: exits 1, naming the failed steps; `tests/build/test_cli_exit.py` |
| E1 | The default part (a 7020) cannot close 250 MHz; the spec named no part | **frames**: "the part and the clock" added to *Decided by the spec* (`stream_kernel`, `stream_pipeline`) |
| E2 | One class at several widths: `cpp_kernel_name` is class-level, so the agent wrote thin subclasses | open (the `param_supports` item) |
| E3 | `ArrayUtilsStep` writes beside the element's `include_dir` (the root when unset) | open (a doc line) |
| E4 | `--status` crashed on a Windows console (`UnicodeEncodeError` on the check mark) | **fixed**: ASCII where the console cannot encode it |
| E5 | `waveflow_validate_schema` failed on a text with a `@dataclass` (`'NoneType' object has no attribute '__dict__'`) | **fixed**: the text runs as a registered module; `tests/mcp/test_schema_tools.py` |
