### New gaps, each checked against the code

- **`harness`'s `n_cycles` is on no harness page** (real, doc).  `harness(module, workload, n_cycles=4000)`
  bounds the RTL run; `units_harness.md` does not mention it (only `units_calibration.md` passes it, in
  an example).  Rung 3 asked how the bound is set; rung 1 did not see it.  Both plans need it.
- **`command_response.md` says `DataUnion`'s C++ "has no stream methods yet"** (real, a stale doc).
  Since 6b526d73 a `DataUnion` generates `array`, `stream`, `axi4_stream` and `framed_stream` readers
  and writers.  Rung 3 rejected `DataUnion` on that sentence (tag-first `DataList`s are accepted by the
  key, so no fault).
- **A Python write of one burst made of several schemas** (rung 3; the agent's misreading, a doc gap
  under it).  `StreamIFMaster.write` takes raw words, so `write(np.concatenate([m.serialize(word_bw=W)
  ...]))` is the call; `tagged_union.md#writing` builds that array and says "one `write`" but never
  shows the `write`.  One line there would close it.
- **No conditional select in `waveflow.hw.fixpoint`** (rung 1; real).  It selects on `.val` with
  `np.where` and rewraps in a stated format -- the documented escape hatch.
- **Signed x unsigned raises** (rung 1; real, the documented v1 limit in `fixed.md`).  It promotes
  `invnoise` to `ap_fixed<17,9>` (exact) on both sides.  A constraint handled, not a missing feature.
- **No framework throughput / cycle-count step for a harness** (rung 1; real).  It writes an example
  `ThroughputStep` over `cycles.bin`; rung 3 does the same in pytest.  Matches 01b's "a harness run
  reports no cycle count".
- **No free-running stream example on complex fixed-point elements** (rung 1; real for a stream
  kernel -- `examples/schemas/complex` covers the type and its lane routines, not on a stream).
- **`ArrayUtilsStep` on an integer element "untested"** (rung 3; the agent's narrow reading:
  `examples/block_scale` builds `ArrayUtilsStep(Int32, ...)`, and the header is `<stem>_array_utils.h`).
- **No example of a 256-bit framed link** (rung 3; real for examples -- the generator is covered by
  `tests/build/test_wide_framed_link.py`).
