Recovery

1. Restore

Read authoritative checkpoint.

Experiment ID · revision · budget · evidence IDs

→

2. Validate

Match session binding.

Reject stale responses and mismatched experiments.

→

3. Deliver

Submit domain context.

Record exact exposure; retain domain accounting.

Submission records prove context delivery by the adapter, not provider receipt.

Policies

pull · default

Agent requests context. Checkpoint available through the existing context tool.

resume · optional

Pi restores the checkpoint at session start and supplies it before the next agent run.

Same evidence access and domain authority. Existing Pi tools retain host permissions; the extension is not a sandbox.

Run

uv run python -m examples.dse_fir --root ./fir-run context
uv run python -m examples.dse_fir.recovery_probe --root ./new-recovery-run

Pi: set WAVEFLOW_DSE_PYTHON, WAVEFLOW_DSE_ROOT and optionally WAVEFLOW_DSE_CONTEXT_POLICY=resume; load pi/index.ts.

Evidence limits

Real fixed-point Python evaluation. Recorded HLS estimates. No live synthesis or RTL.

Recovery tests verify plumbing. Model-dependent efficiency and search gains remain unmeasured. Future comparisons require matched tasks, model, permissions and budget ceilings.
