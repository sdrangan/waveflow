Walk it in four steps; in Present mode each step fades in. 1. The build pipeline: one Python model, simulated, turned into HLS, then RTL. 2. Functional verification: the simulator's output is the golden; RTL must match it bit for bit, and a mismatch is a model or codegen bug fixed in the Python. This is built, with 177 RTL gates. 3. The outer loop, slow and sparse: RTL runs calibrate a timing and resource model per block, which the simulator uses. Partial: a few kernels. 4. The inner loop, fast: explore designs in the simulator alone. Not built. The AI chip marks agent-assisted codegen: the tooling exists, its value is unmeasured.
