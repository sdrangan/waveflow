Adapted from the SALSA paper draft · each tile handles the antennas of one RF chip

Scale to a fully digital array of 1000+ antennas: no single digital chip, SALSA included, can take every stream. So the processing is distributed. Each RF and mixed-signal chip feeds one distributed tile, which could be a SALSA chip. Filtering and data-plane work run over wide bandwidth but few streams, so they distribute naturally. Control-plane work needs all antennas but few degrees of freedom, so it is centralized in a few common tiles. Neighboring tiles are chained to accumulate partial beamforming sums.
