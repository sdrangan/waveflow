Design options: tag in the header vs. task→tasklet map · FIFO vs. priority queues · tasklet granularity

Each PE holds several tasklets. A packet carries its task_id; the PE's task-to-tasklet map picks the tasklet, whose code also names the next hop. One tasklet does a PE's whole share of a task: for OFDM, the FFTs of all antennas in one packet. Queues are first-in, first-out today; priority queues are an option to explore.
