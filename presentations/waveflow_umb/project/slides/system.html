T1 · data plane: filter → OFDM → projection → equalize

T2 · long-term BF: filter → SRS → covariance → weights

The host writes each PE's tasklet code and task→tasklet map · the shared systolic PE runs one tasklet from each task

Two tasks share the chip. The data plane runs every slot; the long-term beamforming update runs every few milliseconds and lands on the same systolic PE. When it does, queueing on that PE delays the data plane: this is where timing depends on interactions, not on fixed block delays. Mapping, priorities and queue depths are the design questions.
